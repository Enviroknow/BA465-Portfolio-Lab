# BA 465 — Portfolio Decision Lab

An interactive learning exercise for **BA 465 Investments, Week 4** at Alaska Pacific University.

## Open the lab

Once GitHub Pages is enabled, the student-facing link is:

https://enviroknow.github.io/BA465-Portfolio-Lab/

## For students

1. Open the Portfolio Decision Lab in a current web browser.
2. Start with the **Long-term growth-equity endowment** mandate and load its example allocation.
3. Record the five weights in **Part C** of the Week 4 Investment Analysis Workbook.
4. Select the **Recession** market condition; record the return and portfolio ending value.
5. Change at least two allocations, keep the total at 100%, and respect the mandate's illustrative limits. Retest the same recession scenario.
6. Choose **Income-oriented institutional fund** or **Short-term operating reserve**, load its example, and test the recession again.
7. Test one additional market condition and complete the workbook interpretation questions.

## Instructor notes

- This is a **fictional instructional model**. Its mandates, asset-category returns, and portfolio assumptions are not APU's actual investment policy or historical market results.
- The tool does **not** retrieve real financial data, recommend stocks, calculate historical volatility/correlation, or determine an optimal portfolio.
- It is a single-file static site; no external packages, keys, database, or student login are necessary.
- For GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**.
- To revise the site later, edit the root-level `index.html`. Changes to that file will be reflected after GitHub Pages finishes publishing.

## Privacy

Calculations run in the student's browser. No student information or investment selections are transmitted by the lab.
